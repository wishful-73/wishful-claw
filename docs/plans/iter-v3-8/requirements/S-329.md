## 四、扫描口径（比补标记本身更重要）

### 4.1 坑

只认中文关键字的扫描，会把所有英文豁免判成「无标记」。这是**双向**的坑：既报假欠账（本单的 3 个大文件），也会在别人按这个口径复扫时把刚补的中文标记判成英文之外的写法而漏认。

### 4.2 复扫脚本必须照这个判据

```
判据：全仓扫超 500 行全集 → 减去「有标记集合」→ 差集非空即欠账
标记识别要认三种写法（缺一不可）：
  1. 500 行豁免          中文安宁式，AGENTS.md:188 规定格式
  2. 超标待拆分           AGENTS.md:197 规定的欠账登记
  3. 500-line exemption  英文写法（历史遗留，仍在服役）
  并且只看文件头前 25 行 —— 标记必须写在文件头，写在中间的等于没有
```

`AGENTS.md:188` 规定的正式格式仍是中文那一条。英文写法属历史遗留，**不强制迁移**（改注释会污染 `git blame`），但**必须能被扫描认出来**。
