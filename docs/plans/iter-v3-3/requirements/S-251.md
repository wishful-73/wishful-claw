## 3. 硬约束

1. **方法体逐字平移**：不改一行逻辑、不改日志、不改异常文案、不改 `CancellationToken` 传递方式。
2. **`partial class` 声明一致性**：同一类的所有分部必须 `static` 修饰一致；`OpenAIChatProvider` 是 `internal static partial`，新分部必须同样写 `internal static partial class OpenAIChatProvider` 并在同一命名空间。
3. **私有成员可见性**：`private` 成员在同一类的各分部之间天然可见，无需改可见性 —— **严禁为了方便而把 `private` 提成 `internal`**。
4. **AGENTS.md 既有条款继续生效**：`JsonArray.Add<T>(T)` 不得改回泛型；新增文件不引入 AOT 警告（`dotnet build` 必须 0 警告）。
5. **拆完头部标注清理**：分部文件无需标注，主文件降线后删掉「超标待拆分」三行注释。
