## 三、三个现象的根因（**均已坐实**）

### 3.1 三栏挤爆 ⇒ 重叠

`GitPage` 按**宿主宽度**切形态（`ResizeObserver`，`:87-96`），宽形态三栏并排：

| 栏 | 宽度 |
|---|---|
| `ScmSidebar` | 固定 `scmWidth`，默认 **360** |
| diff 区 | `flex-1` |
| 文件历史 | 固定 `historyWidth`，默认 **300** |

**根因**：阈值 `GIT_PAGE_COMPACT_MAX_WIDTH = 640`（`:31`）与三栏**实际所需宽度不匹配** —— 640 就切三栏，但 360 + 300 + 可用 diff 实际要 **800+**。面板落在 **640 ~ 约 800** 区间时，两栏固定宽把中间 `flex-1` 挤成负值 ⇒ **三栏重叠**。

⇒ 老大「我之前不知道」—— 默认宽度 384 落紧凑形态，本来碰不到；**拉宽**才触发。

### 3.2 「只有一个文件夹」⇒ 未跟踪目录没展开

`GitStatusTools.StatusDetailedAsync`（`src/runtime/WishfulClaw.Agent/Modules/Git/GitStatusTools.cs:16`）执行的是：

```csharp
new[] { "status", "--porcelain=v1", "-b" }
```

**没带 `-uall`（`--untracked-files=all`）** ⇒ git 用默认 `--untracked-files=normal`，把未跟踪**目录折叠成一条**（如 `?? docs/plans/iter-v2-39/`）。

⇒ SCM 列表的「未跟踪」区里就**只有一个目录条目**，目录下的文件一个都看不到。这正是老大说的「只有一个文件夹」。

### 3.3 「说明」= 中间区的提示文字

选中那个目录条目时，目录本身**没有 diff 可算**，中间 diff 区只能显示提示文字（`untrackedNoDiff` / `noDiff` / `pickFile` 之一）。老大 10:46 说的「还有个 说明还是什么」即此。
