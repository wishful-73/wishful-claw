# Wishful Claw 使用指引

Wishful Claw 是一款跑在你自己电脑上的 AI Agent 工作台。你用一句自然语言交代任务，它就能读写你的项目文件、执行命令、搜索代码、操作浏览器，并把做过的事记住——下次打开还在。

本指引按「先跑起来 → 再逐块了解」的顺序编排。只想快速看一眼能做什么，读[根 README 的功能清单](../README.md#-它能为你做什么)即可。

## 1. 安装与启动

1. 到 [Releases 页面](https://github.com/wishful-73/wishful-claw/releases/latest) 下载最新的 `wishful-claw-x.y.z-setup.exe`，双击安装。
2. 首次启动后不需要额外运行时，安装包已内置全部依赖。
3. 你的所有数据都在用户目录下，卸载应用不会自动删除，换机时整个目录拷走即可继续用：

| 位置 | 内容 |
|------|------|
| `~/.wishful-claw/` | 数据库、服务商配置、全局记忆与人格、插件与渠道配置 |
| `~/.wishful-claw/logs/` | 按日期切分的运行日志，如 `2026-09-12.log` |
| `{项目目录}/.wishful-claw/` | 项目级记忆与人格，随项目走，可用 Git 版本管理 |

> Windows 下 `~` 即 `C:\Users\<你的用户名>`。

## 2. 配置模型（第一次打开必做）

应用本身不带模型，需要你自己的 API Key。

1. 左侧栏底部 **设置** → **AI 服务商**。
2. 从预设里选一家（Anthropic、OpenAI、Gemini、OpenRouter、智谱、Kimi、DeepSeek 等），填入 API Key；自建网关可以改 Base URL 和模型列表。
3. 点 **测试连通性**，成功后把这个服务商设为当前使用。
4. 之后每次对话用的就是这个「全局激活模型」，也可以在输入区临时切到别的模型。

### 辅助模型与补位模型

有几类后台请求你在对话流里看不到具体是哪个模型在跑：提示词优化、新建人格时的 AI 辅助生成。**设置 → 运行与性能 → 辅助模型** 可以给它们分别指定模型，还可以配一个**补位模型**作为统一兜底。

解析顺序固定为三级：**该请求自己的显式配置 → 补位模型 → 全局激活模型**。三级都不可用时会明确报错，不会悄悄用一个已经删掉的模型。

## 3. 界面导览

```
┌────────────┬──────────────────────────────────────┬─────────────┐
│  左侧栏    │              主内容区                │  右侧面板   │
│ 项目/对话  │   会话 · 设置 · 定时任务 · 任务看板  │ 执行/文件/… │
└────────────┴──────────────────────────────────────┴─────────────┘
```

- **左侧栏**：新对话、搜索（命令面板）、扩展（自动化 / 任务看板）、项目列表、对话列表、设置。项目可以按名称或最近更新排序，支持重命名、置顶、归档。
- **顶栏**：最左侧是侧边栏折叠；右侧依次是 **使用指引（问号图标，打开本文档）**、文件、终端、右侧面板开关、窗口控制。会话标题在折叠区中间显示。
- **右侧面板**：执行过程、文件树、预览、内置浏览器、终端（本地或 SSH）、会话摘要、变更审阅。
- **输入区**：模型选择、协作模式、权限模式、计划模式开关，图片附件、上下文占用指示、提示词一键优化。

## 4. 发起第一个任务

### 项目会话与全局会话

- **项目会话**：绑定一个工作目录，Agent 在其中读写文件、跑命令。左侧栏 **项目** → 新建项目，选本地目录或 SSH 远端目录。
- **全局会话**：不绑定目录，用于问答、整理信息、跨项目协调。它只读不写工作区，适合当日常助手。

### 协作模式

- **对话（chat）**：一问一答，动手前会先跟你确认方案。
- **协作（cowork）**：Agent 自主连续工作，自己拆步骤、调工具、验证结果，中途只在需要你决策时停下来。

### 计划模式

开关打开后，Agent 先用只读方式浏览代码，产出一份分步计划，等你批准后才开始改文件。改动面大的重构、不熟悉的老项目，建议先走计划模式。

### Goal 模式

给一个目标，Agent 按 plan → execute → verify → continue/adjust 循环自己推进并自检，直到目标达成或需要你介入。目标的历史与状态可以在 Goal 面板查看。

### 长对话怎么管

- **插话排队** —— Agent 正在干活时你还能继续发消息，消息进队列，等当前这轮结束按序处理，不用打断它。
- **上下文压缩** —— 接近上下文上限时自动做摘要式压缩，保留关键结论；你也可以手动触发一次。
- **会话管理** —— 会话列表里可重命名、复制、置顶、清空、删除；右侧面板的会话摘要能回看已做过什么。

## 5. 权限模式与工具确认

输入区的权限下拉有两档：

| 档位 | 行为 |
|------|------|
| **默认** | 写文件、删除、执行命令一类操作弹出确认卡，读操作不打扰 |
| **YOLO** | 全部操作自动放行，不再询问（切换到该档需要二次确认） |

确认卡上会标明操作风险等级（危险 / 注意 / 安全）、展示完整入参，并提供：

- **本次允许**
- **允许并加入白名单** —— 支持通配符与正则，之后同类操作不再询问
- **自动批准所有** —— 当前会话内不再询问

渠道（微信 / 飞书等）会话里的命令执行有独立的授权策略，可在渠道设置中调整。

## 6. 记忆系统

记忆分三层，应用会自动在层间流转，你不需要手工搬：

| 层 | 载体 | 说明 |
|----|------|------|
| **Hot** | `MEMORY.md` 文件 | 当前活跃记忆，按 `##` 分段，Agent 实时读写，纯文本可手改 |
| **温** | SQLite 记忆表 | 结构化条目，全文检索 |
| **冷** | 归档条目 | 超预算后降级留存，需要时可召回 |

你能用到的功能：

- **自动回忆** —— 每次对话开始前，应用会检索与本次话题相关的记忆注入上下文，Agent 会把它当参考资料而不是指令。
- **主动读写** —— Agent 可以把「你偏好的写法」「上次踩的坑」写进记忆，也能主动搜索历史记忆。
- **每日自动整理** —— **设置 → 记忆** 可开启定时整理，合并重复、清理过期、把冗长条目压缩成摘要，并设置降级阈值。
- **记忆面板** —— 右侧面板「记忆」可查看三层内容、搜索、手动触发一次整理。
- **作用域** —— 全局记忆（跨项目共享）与项目记忆（只在该项目内生效）分开，落在第 1 节说的两个目录里。

> 记忆是文件 + 数据库，你可以随时手工编辑 `MEMORY.md`，也可以直接删掉不想要的条目。

## 7. 人格系统

人格只影响**输出给你的那段话**——语气、措辞、详略——不参与 Agent 的任务决策，所以换人格不会让任务跑偏。

- **人格管理**（设置 → 人格管理）：新建、编辑、复制人格，每份人格由身份（我是谁）与灵魂（我怎么说话）两部分组成，还可定制认知与行为准则。
- **内置预设**：桃子、老郑、贾维斯、小爪、婷姐、阿明，各有风格。
- **AI 辅助创建**：描述你想要的人格，自动生成初稿再手工微调。
- **绑定**：可以设全局默认人格，也可以给单个会话或单个项目指定不同人格。
- **作用域**：全局人格库与项目人格库分开管理。

## 8. 工具能力一览

Agent 具体能使什么，取决于当前会话类型与权限模式，以下是产品已具备的能力面：

| 类别 | 能力 |
|------|------|
| 文件 | 读、写、编辑、列目录、按文件名匹配 |
| 代码检索 | 全文搜索、代码图谱索引与语义检索（大项目找调用链更快） |
| 终端 | 执行 Shell 命令，支持本地与工作目录；长命令有输出限额保护 |
| 浏览器 | 内置浏览器导航、快照、点击、输入，可用于查资料和验证网页效果 |
| 图片 | 文生图（需在插件里指定图像模型）、读取图片内容 |
| 桌面 | 整桌面截图（用于取证或让你看清当前状态） |
| 远程 | SSH 连接管理、远端目录作为项目工作区、远端命令执行 |
| 子任务 | 派发子 Agent 并行处理独立问题，嵌套深度受限，结果汇总回主会话 |
| 任务管理 | 步骤清单的增删改查与状态跟踪 |
| 定时 | 创建/管理定时任务，见第 11 节 |
| 渠道 | 收发消息、群与成员查询，见第 10 节 |
| 提问 | 需要你做选择时弹出选项卡（可多选、可补充说明） |
| 扩展 | 调用插件、Skills、MCP 服务器提供的工具 |

工具不会一次性全部塞进上下文：核心工具直接在系统提示词里，其余的 Agent 按需查询和调用，因此工具再多也不会拖慢对话。

## 9. 扩展能力：插件 / 扩展 / Skills / MCP

四个入口都在设置页，作用不同：

- **插件**（设置 → 插件）：内置能力开关，含 Image（文生图）、Browser（浏览器）、CodeGraph（代码图谱）、Desktop-control（桌面控制）。可启用/停用，并为其指定独立模型。
- **自定义扩展**（设置 → 自定义扩展）：安装本地扩展包，扩展可以带来新工具和自定义界面组件。
- **Skills**（设置 → Skills）：给 Agent 装配「某类任务的标准做法」。支持查看已安装列表、从在线市场安装、从本地文件夹安装。
- **MCP**（设置 → MCP）：连接外部 MCP 服务器，把它们提供的工具接进 Agent。支持手动添加、JSON 配置导入、在线市场。

用不上时停用即可，停用后对应工具不会出现在 Agent 的可用面里。

## 10. 渠道集成（微信 / 飞书 / QQ 等）

把 Agent 接到你日常用的聊天软件，在外面也能派活、收结果。

**支持的平台**：微信、飞书、QQ 机器人、钉钉、企业微信、Telegram、Discord、WhatsApp。

**配置流程**：

1. 设置 → 渠道配置，选一个平台。
2. 填凭据（多数平台需要你在平台侧创建机器人 / 应用，把 App ID、Secret、Token 粘回来），微信支持扫码登录。
3. 绑定一个项目会话——渠道收到的消息会由该会话的 Agent 处理。
4. 启用并连接，之后在聊天软件里 @ 机器人即可对话。

**行为说明**：

- 自动回复默认开启；不需要时可以在设置里关掉，改成只在被提及时响应。
- 应用启动时是否自动拉起已启用渠道，由全局设置控制。
- 渠道会话里的命令类操作，默认需要你确认，可以改成免确认直接执行。

## 11. 定时任务与任务看板

### 定时任务（左侧栏 → 扩展 → 自动化）

到点自动跑一件事，适合日报、定期巡检、批量整理。

- 列表视图与日历视图两种看法。
- 新建时可设定周期或单次时间、提示词、执行模型。
- 两种执行方式：**随指定会话执行**（结果出现在那个会话里，能延续上下文）与**后台执行**（不占用会话，工具面更收敛，适合纯自动作业）。
- 支持启用 / 停用 / 立即运行一次 / 归档。

### 任务看板（左侧栏 → 扩展 → 任务看板）

把待办做成卡片：建卡、设状态与优先级、直接派发给 Agent 执行，适合管理一批并行任务。

## 12. 效率工具：启动器与剪贴板

这两个是脱离主窗口也能用的全局能力。

- **快速启动器** —— 默认 `Alt + Space` 唤起，输入几个字符即可启动已安装程序、打开应用内页面。支持词首字母缩写匹配（例如输入 `cc` 能命中 Chrome）。
- **剪贴板历史** —— 默认 `Ctrl + Shift + V` 唤起面板，翻查历史复制记录，选中后粘贴回你原本聚焦的那个窗口（包括浏览器和其他软件）。
- 两者的开关与快捷键都在 **设置 → 快捷键**。

## 13. 外观、语言与快捷键

- **主题**：浅色 / 深色 / 跟随系统。
- **配色方案**：黑曜灰、远航蓝、石墨工具、深海青、松林绿、暖曦橙。

## 14. 用量统计与成本

**设置 → 用量统计** 看模型请求的真实开销：

- 时间窗：24 小时（按小时分桶）/ 7 天 / 30 天（按天分桶）。
- 汇总卡：请求数、计费输入 token、输出 token、缓存读取 token、成本、平均耗时。
- 分桶柱状图中失败请求以红色叠加显示，一眼看出哪个时间段在报错。
- 两张汇总表：**按模型**（哪个模型花得多）、**按来源**（会话、子 Agent、后台自动化、辅助请求各自占比）。
- 明细表列出最近 50 次请求，含重试次数与失败原因。

> 成本按你在服务商里配置的价格结算；没配价格的模型显示为 `—` 而不是 `$0.00`，避免误读成免费。

## 15. 更新与日志

- **检查更新**：设置 → 关于 → 检查更新。可以打开「启动时自动检查」；**下载与安装始终需要你确认**，不会静默更新。
- **日志**：设置 → 日志 可在线查看与导出；磁盘位置为 `~/.wishful-claw/logs/YYYY-MM-DD.log`，包含主进程、渲染进程、Worker 与 IPC 四类来源。反馈问题带上当天日志能显著加快速度。

## 16. 常见问题排查

| 现象 | 先查这里 |
|------|---------|
| 对话没有任何回复 | 设置 → AI 服务商 → 测试连通性；确认 API Key 余额与模型名可用 |
| 提示模型不存在 / 服务商已删 | 重新选定全局激活模型；辅助请求会走补位模型兜底 |
| 后台/辅助请求走的模型不对 | 设置 → 运行与性能 → 辅助模型，检查该请求的显式配置与补位模型 |
| Agent 说找不到某个工具 | 该工具所属插件可能被停用；到设置 → 插件 / MCP / Skills 确认启用状态，或当前会话类型不开放该工具 |
| 命令执行频繁弹确认 | 会话权限模式改法见第 5 节；渠道会话看渠道设置 |
| 记忆没被用到 | 右侧记忆面板确认条目确实写入；检查设置 → 记忆 的主动回忆与整理开关 |
| 启动器 / 剪贴板快捷键没反应 | 与其他软件的全局热键冲突，到设置 → 快捷键换一个组合 |
| 安装后没有联网权限报错 | 防火墙放行应用；企业网络下确认代理设置 |
| 更新下载失败 | 到 Releases 手动下载安装包覆盖安装，配置与数据不会丢 |

再解决不了，把 `~/.wishful-claw/logs/` 当天日志的 `[ERROR]` 段落带上提问。
