# S-183：项目档案页 —— 内容区缺少高度约束，内容被裁且不出滚动条

> 状态：**已登记**（2026-10-10），**待开工**；根因已**静态读码定位**（**未启动实例实测**，实测留到开工）。
> 类型：**渲染端布局缺陷**（`src/renderer/`），范围 = 项目档案页（`ProjectArchivePage`）的 **tab 内容区**。
> 归属：iter-v2-39。

---

## 一、原话 / 来源

老大 2026-10-10 09:36：

> 「登记系列bug 主要集中在项目档案页面 1.项目记忆，记忆库 等文档或列表缺少高度限制也不出滚动条，导致内容直接被遮挡无法查看」

---

## 二、现象

项目档案页里凡是**内容超过一屏**的文档 / 列表：

- **看不到滚动条** —— 无论内容多长，容器内都不出现滚动条；
- **内容被裁** —— 超出一屏的部分直接消失，且**滚不到**，等于「被遮挡无法查看」。

老大点名「项目记忆 / 记忆库」，但读码看**三档（项目记忆 / 记忆库 / 项目人格）共用同一条容器链**，人格档同样受影响。

---

## 三、根因（静态读码定位，**未实测**）

**一句话：`ProjectArchivePage` 的中间层是普通块级 div，不在 flex 高度链上，把整条 `flex-1 + min-h-0` 链掐断了。**

容器链（自外向内）：

| # | 位置 | class | 判定 |
|---|---|---|---|
| 1 | `ProjectArchivePage.tsx:200` | `relative flex flex-1 flex-col overflow-hidden bg-background px-6 pb-6 pt-4` | 根容器，正常；`overflow-hidden` 是裁切来源 |
| 2 | `ProjectArchivePage.tsx:201` | `mx-auto w-full max-w-[1480px]` | 🔴 **普通块级 div** —— 无 `flex` / `flex-1` / `min-h-0` / `h-full` |
| 3 | `ProjectArchivePage.tsx:300` | `flex min-h-0 flex-1 flex-col overflow-hidden pt-4` | tab 内容区；父级不是 flex 项 ⇒ `flex-1` **失效** |
| 4 | `ProjectMemoryFileTab.tsx:106` | `flex min-h-0 flex-1 flex-col overflow-hidden` | 同上，**失效** |
| 5 | `ProjectMemoryFileTab.tsx:159` | `mt-3 flex-1 overflow-auto` | 🔴 内容滚动容器；高度 = 内容自然高度 ⇒ **永不溢出 ⇒ 不出滚动条** |
| 6 | `ProjectMemoryFileTab.tsx:176` | Textarea `min-h-[480px]` | 把内容进一步撑高 |
| 7 | `ProjectMemoryLibraryTab.tsx:283` / `:376` | 与 4 / 5 同构 | 同上 |

**传导过程**：

1. 第 2 层不参与根容器的 flex 分配 ⇒ 高度退化为**内容自然高度**；
2. 第 3~6 层 `flex-1` 逐级失效 ⇒ 内容容器高度 = 内容高度 ⇒ `overflow-auto` **永不触发**；
3. 根容器（第 1 层）是 `overflow-hidden` ⇒ 超出视口的总高度被**静默裁掉**。

⇒ 与现象逐条对上：**不出滚动条**（第 2 点）+ **内容被遮挡无法查看**（第 3 点）。

---

## 四、修复方向（**待开工时定**，此处只记方向）

- 让第 2 层进入 flex 高度链：`mx-auto flex min-h-0 w-full max-w-[1480px] flex-1 flex-col`（保留 `mx-auto` + `max-w`）。
- 复核同层内 `CodeGraphProjectIndexSection`（`:275-277`）与 tab bar（`:280-297`）是否需 `shrink-0`，确保内容区拿到剩余高度。
- 复核第 5 / 7 层 `overflow-auto` 生效后，`min-h-[480px]` 的 Textarea 是否仍必要（短内容也会被撑到 480px）。

---

## 五、验证方式（待开工执行）

dev 实例 → 项目档案页：

1. **项目记忆**：打开内容长的 `MEMORY.md` ⇒ 内容区应出滚动条、底部可达；
2. **记忆库**：条目多时列表应出滚动条；
3. **项目人格**：预览区应受高度约束，不无限拉长；
4. 矮窗口 / 窄窗口下不出现「整页无滚动条且内容被裁」。

回归面：页面外层仍应保持 `overflow-hidden`（**不引入整页滚动条**）。
