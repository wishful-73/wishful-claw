## 六、实施（2026-09-30，第 2 刀）

**落点**：`src/renderer/src/components/settings/PersonaPanel.tsx`（全局人格页与项目人格页**共用**这一个组件 —— 项目侧传 `workingFolder`，全局侧不传）。

**改动**（**1 个文件，纯改**）：

1. 头部工具栏在「新建人格」左侧加一个 `variant="outline"` 的「AI 创建人格」按钮，图标复用已有的 `Sparkles`（该图标此前只用于空态占位）。文案复用既有 i18n key **`persona.aiCreate`** —— 它原本只是弹窗标题（「AI 创建人格」/「AI Create Persona」），语义与入口按钮一致，**zh / en 两份 locale 均零改动**。
2. 新增 `generatorOpen` state，按钮 `onClick` 置 `true`。
3. 组件根部渲染 `<PersonaGeneratorDialog open={generatorOpen} onClose={...} workingFolder={wf} />`。

**未传 `onSaved`**：`persona-store.ts` 的 `savePersona` 已自刷列表并重选，且 `PersonaGeneratorDialog.handleSave` 在 `onSaved?.()` 之后自己调 `handleClose()` ⇒ 外部只需管 `open`。多传一个空回调属于噪声。

**未加 dirty 拦截**：AI 生成走的是「新增一份人格」，不动当前编辑中的 `draft`；与 `handleNewPersona` / `handleSelectPersona` 那两个「会切换选中项」的动作不同，不需要复用 `unsavedConfirm` 弹窗。

**项目侧一并生效**：入口对全局页与项目页同时出现，`workingFolder` 原样透传 ⇒ 在项目上下文里生成的人格直接落项目人格库。这是既有 props 语义，不是新增行为。

**门禁（本刀实跑）**：`npx tsc --noEmit` 三配置（web / node / root）全 `EXIT=0`；`npm test` **61/61**（TS 45 + C# 16）。
