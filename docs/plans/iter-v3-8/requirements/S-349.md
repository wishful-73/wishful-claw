## 二、为什么当时没改（不是疏忽，是判断错了）

S-342 当时的排查结论是：这两处调用点的代码**是对的**，只是不依赖那个选择器 ——

- `SubAgentsPanel` 直接读三个全局 map（`activeSubAgents` / `completedSubAgents` /
  `subAgentHistory`），然后靠下游 `mergeSessionSubAgents` 按 `sessionId` 过滤；
- `SubAgentExecutionDetail` 靠 `toolUseId` 全局唯一去查，不需要按会话分组。

于是「代码不用动」→「注释也不用动」。**这是错的**：注释写的是「因为它是桩，
所以我绕过」，而现在它**不是桩**了，注释给后来人留的是一个已经不存在的前提。
下一个人读到这句，会以为团队/子代理这块儿还有一坨没接通的桩代码，白白浪费排查时间。
