## 三、官方要求（**四页实读，2026-10-14**）

### 3.1 深度思考（`.../text-generation/deep-thinking`）

- 参数只有 `thinking.type` = `enabled` / `disabled`；文档明确「**`thinking` 字段并非 OpenAI 标准参数**」（走 OpenAI SDK 要放 `extra_body`；我们 C# 直接写 body，不受影响）⇒ **我们的写法一字不差，不改**。
- 支持思考的模型：`mimo-v2.6-flash` / `mimo-v2.6-pro` / `mimo-v2.6-pro-ultraspeed` / `mimo-v2.5-pro` / `mimo-v2.5`。
- **默认「开启」**（上列全部）⇒ 关闭必须显式下发 `disabled`（我们已有 `disabledBodyParams`，满足）。
- **`temperature` / `top_p` 思考下不支持自定义**，传了也被强制为 `1.0` / `0.95`（不报错，**静默失效**）。
- `max_completion_tokens` 管**思考 + 回答的总长**。
- **多轮工具调用**：assistant 消息**只要含 `tool_calls` 就必须完整回传 `reasoning_content`，否则 API 返回 400**；官方点名受影响产品含 **OpenClaw / OpenCode**（我们同类）。
  - **我们已满足**：`OpenAIChatRequestBuilder.cs:175-181` 恰好在 `message.ToolUses.Count > 0` 时写 `reasoning_content`（不多不少）。

### 3.2 模型清单（`.../summary/model`）

| 模型 ID | 能力 | 长度 | 限流 |
|---|---|---|---|
| `mimo-v2.6-pro` / `mimo-v2.6-flash` | 文本生成 + **全模态理解** + 深度思考 + 流式输出 + 函数调用 + 结构化输出 + 联网搜索 | 上下文 **1M** / 最大输出 **128K** | 100 RPM / 10M TPM |
| `mimo-v2.6-pro-ultraspeed` | （官方表该行能力列为空，**待核**） | 1M / 128K | 定制服务 |
| `mimo-v2.5`（即将下线） | — | 1M / 128K | 100 RPM / 10M TPM |
| `mimo-v2.5-pro`（即将下线） | 文本生成 + 深度思考 + 流式 + 函数调用 + 结构化输出 + 联网搜索（**无「全模态理解」**） | 1M / 128K | 100 RPM / 10M TPM |

ASR：`mimo-v2.5-asr`；TTS：`mimo-v2.5-tts` / `-voiceclone` / `-voicedesign`。

## 五、待确认（**实施前必须定**）

1. **`supportsVision`**：官方把 v2.6-pro / flash 的能力写成「**全模态理解**」，而我们现值的 v2.5-pro 是 `false`、v2.5 是 `true`（且官方 v2.5-pro 能力列里**没有**「全模态理解」）。⇒ v2.6 是否置 `true`、以及我们渲染层「全模态」的语义边界（图片？音频？视频？），**得先定**。
2. **`deprecatedModelIds`**：10-21 下线是确定的，但 **18:00～10-21 之间是「自动转发」期**（能跑）。现在加进 deprecated 会**立刻清掉**老用户已配好的 v2.5 记录 —— 是「现在清」还是「10-21 之后再清」，需要口径。
3. **`defaultModel` 换不换**：换成 `mimo-v2.6-pro` 会让新用户默认走 6 倍价的模型（相对 v2.5），要不要保守留在 flash。
4. **套餐（Anthropic 协议）的思考写法**：官方文档讲 `thinking.type` 是在 OpenAI 兼容语境下；Anthropic 协议侧我们走 `buildAnthropicThinkingConfigWithBudget`（`ModelSettingsPopover.tsx:135`，带 `budget_tokens`）。**小米 anthropic 端点是否同样接受 `{type:'disabled'}`**（Anthropic 原生语义里「关闭 = 不传字段」），**未验**。
5. **`mimo-v2.6-pro-ultraspeed` 的能力列**：官方表该行为空，是否与 pro/flash 同（含「全模态理解」）待核。
