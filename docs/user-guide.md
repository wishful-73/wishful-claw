Wishful Claw 是一款跑在你自己电脑上的 AI 智能助手。你用一句平常话交代任务，它就能读写你的文件、执行命令、搜索内容、操作浏览器和桌面软件，并且把做过的事记住——下次打开还在。

模型你自己选、API Key 你自己带，不绑定任何一家。软件装完就有免费对话可以先问起来，想让它在电脑上真干活再配 Key。

## 1. 安装与启动

1. 到 [Releases 页面](https://github.com/wishful-73/wishful-claw/releases/latest) 下载最新的 `wishful-claw-x.y.z-setup.exe`，双击安装。当前提供 Windows 版，macOS 与 Linux 的安装包在准备中。
2. 首次启动不需要额外运行时，安装包已内置全部依赖。
3. 打开后先过一屏初始设置：填一个**称呼**（AI 怎么叫你）、选**语言**和**外观**，再挑一个常用的**对话角色**，之后就直接进主界面。
4. 你的所有数据都在自己的用户目录下，卸载应用不会自动删除；换机时把整个目录拷走即可继续用：

| 位置 | 内容 |
|------|------|
| `~/.wishful-claw/` | 数据库、服务商配置、全局记忆与人格、插件与渠道配置 |
| `~/.wishful-claw/logs/` | 按日期切分的运行日志，如 `2026-09-12.log` |
| `{项目目录}/.wishful-claw/` | 项目级记忆与人格，随项目走，可用 Git 版本管理 |

> Windows 下 `~` 即 `C:\Users\<你的用户名>`。

## 2. 不花钱先用起来：免费对话与效率工具

这一章里的东西都不需要模型 Key，装完就能用。

### 免费对话

装好后第一件事不是配 Key。左侧栏的**免费对话**里内置了一批 AI 服务的网页版——DeepSeek、Kimi、智谱清言、腾讯元宝、豆包——点一下就在软件内置的浏览器里打开，你在页面里登录一次，之后随时点开就能问。

- 查资料、拿不准想问一句、随手翻译和总结，都在这里，跟花不花钱无关。
- 你点开的服务会以选项卡的形式留着，切走再切回来不用重新加载，登录态也留在原地。
- 这份清单可以增删与排序：点这一页右上角的**齿轮**（站点设置）打开面板，顺序就是这一页选项卡的排列顺序。

要让 AI 在你电脑上真动手（读写文件、跑命令、操作桌面），才需要下一步的模型 Key。

### 效率工具

这两个是脱离主窗口也能用的全局能力。

- **快速启动器** —— 默认 `Alt + Space` 唤起，输入几个字符即可启动已安装程序、打开应用内页面。支持词首字母缩写匹配（例如输入 `cc` 能命中 Chrome）。
- **剪贴板历史** —— 默认 `Ctrl + Shift + V` 唤起面板，翻查历史复制记录，选中后粘贴回你原本聚焦的那个窗口（包括浏览器和其他软件）。
- 两者的开关与快捷键都在 **设置 → 快捷键**。

## 3. 配置模型

应用本身不带模型，需要你自己的 API Key。

1. 左侧栏底部 **设置** → **AI 服务商**。
2. 从预设里选一家（Anthropic、OpenAI、Gemini、OpenRouter、智谱、Kimi、DeepSeek 等）。配置面板顶部有一行**官方网站**，点一下就在浏览器里打开，去订阅或买额度；回到软件填 **API Key**。想先零成本试，选提供免费额度的那几家。
3. 自建服务商走另一条：点 **添加自定义服务商**，填 **Base URL** 和 API Key，再点 **拉取模型** 把模型列表取回来；服务商没有拉取接口时，点 **添加模型** 手动录入。
4. 点 **检查连接**，成功后把这个服务商设为当前使用。
5. 之后每次对话用的就是这个「全局激活模型」，也可以在输入区临时切到别的模型。

不设白名单：任何提供兼容接口的服务商都能接，填地址、填 Key、保存即用。

### 辅助模型与补位模型

有几类后台请求你在对话流里看不到具体是哪个模型在跑：提示词优化、新建人格时的 AI 辅助生成。**设置 → 运行与性能 → 辅助模型** 可以给它们分别指定模型，还可以配一个**补位模型**作为统一兜底。

解析顺序固定为三级：**该请求自己的显式配置 → 补位模型 → 全局激活模型**。三级都不可用时会明确报错，不会悄悄用一个已经删掉的模型。

## 5. 项目下会话：干活的地方

会话分两种：**项目下会话**和**全局会话**。日常干活走前者，跨项目的调度和汇总走后者。

### 正常用法

1. 左侧栏 **项目** → 新建项目，选本地目录或 SSH 远端目录。
2. 在这个项目下新建一个会话。
3. 说出你的任务。
4. **你拍板，agent 执行** —— 它给出方案或逐步跟你确认，你点头之后，它才在这个项目的目录里读写文件、跑命令、开浏览器。

要盯细节、要临时调整方向，就在同一个会话里继续说，执行过程和确认卡都在这页上。

### 对话与协作：区别是能给它的工具多少

项目下会话有两种工作模式，切换改变的是**它能拿到哪一批工具**：

- **对话（chat）** —— 只有"看和查"的一类：读文件、搜索、列目录、检索记忆。适合问清楚一件事、看懂一份代码、整理信息。
- **协作（cowork）** —— 额外拿到"改东西"的一类：写文件、编辑文件、开子任务。它会自己拆步骤、连续推进、验证结果，中途只在需要你决策时才停下来。

### 计划模式与 Goal 模式：协作干活时的两种执行方式

这两个不是与"对话 / 协作"并列的第三种模式，而是**协作这一侧怎么把活跑起来**的两种执行方式：

- **计划模式** —— 先只用只读方式浏览，产出一份分步计划，等你批准后才开始改文件。改动面大的整理、不熟悉的老项目，建议先走这一步。
- **Goal 模式** —— 给一个目标，AI 按「规划 → 执行 → 校验 → 继续或调整」循环自己推进并自检，直到目标达成或需要你介入。目标的历史与状态可以在 Goal 面板查看。

### 长对话怎么管

- **插话排队** —— 它正在干活时你还能继续发消息，消息进队列，等当前这轮结束按序处理，不用打断它。
- **上下文压缩** —— 接近上下文上限时自动做摘要式压缩，保留关键结论；你也可以手动触发一次。
- **会话管理** —— 会话列表里可重命名、复制、置顶、清空；右侧面板的会话摘要能回看已做过什么。

## 6. 全局会话：调配资源的那一层

全局会话不绑定某个目录，它管的是"产品经理"那一层的事。需要跨项目安排活、又不想一个个会话去交代时用它；单件具体的事，直接开项目下会话更快。

- **看清家底** —— 查询当前有哪些项目和会话，各自处在什么状态。
- **自己开项目** —— 在你设置的父目录下直接建项目，不用你先手动创建文件夹。
- **派活** —— 给某个项目下的会话发消息安排任务，交代完就让它自己跑。
- **记账与回报** —— 自己维护一份全局任务清单；项目里的会话做完活会更新这份清单，全局会话随即被触动，把结果整理成一段话回给你。

### 它只调配资源，不动手改文件

**全局会话不能新增、修改、删除文件。** 写文件、编辑文件、开子任务这一类工具只在协作模式下可见，而全局会话固定是对话模式，拿不到它们。

它能做的是读你的文件、搜代码、查你有哪些项目和会话、建项目、派活、记账 —— 也就是**调配资源**；真要把什么东西改掉，由它指定某个项目下的会话去做。这个分工不是限制，是因为改文件需要一个明确落点（哪个目录、哪个项目），而全局会话恰恰没有这个落点。

### 让全局会话主动起来

全局会话可以被"触动"，来源有两个：一是项目会话更新任务清单（干完活回来），二是**定时任务**。给它安排一个定时触发点，它就能自己醒来翻账本、催没交的、把一段时间的成果汇总给你，不用你先去问。详见第 13 节。

## 7. 权限模式与工具确认

先说清这笔交易：**你希望它多主动，就得给它多大权限。** 每一步都弹确认，它就只能在你盯着的时候推进；权限给足，它才能在你不在场的时候把活干完。

输入区的权限下拉只有两档：

| 档位 | 行为 |
|------|------|
| **默认** | 写文件、编辑、执行命令、操作桌面这一类"会改东西"的操作弹确认；读文件、搜索、列目录、检索记忆不打扰你 |
| **YOLO** | 所有审批自动放行，不再询问（切换到该档需要二次确认） |

确认卡上只有两个动作：**同意** 与 **拒绝**。没有"这次允许、以后同类不再问"这种中间档，也没有可以自行添加的命令白名单 —— 想让同类操作不再弹确认，目前只有一个办法：把这一档切到 YOLO。

所以真实的取舍就在两头之间：默认档稳妥，但它只能在你盯着的时候推进；YOLO 主动性最高，代价是把边界整个交给它。中间没有第三档，选哪一头取决于你愿意把这件事放手到什么程度。

确认不会丢，但两种入口等待的方式不同：

- **在电脑上直接开的会话** —— 确认弹窗停在当前会话里，你不点它就不往下走；想看进展时随时点回那个会话，它还在原地等。
- **渠道（微信 / 飞书等）** —— 那边没有弹窗可点，确认会以消息的形式发回聊天，你回「同意」就执行、回「拒绝」就取消；**10 分钟内没有回复，按拒绝处理**，不会一直挂着。

渠道侧另有一个总开关：设置 → 渠道配置 → 全局渠道设置 → 安全权限，默认每次执行前要你确认，关掉后渠道里的命令直接跑。

## 8. 记忆系统

记忆分三层，应用会自动在层间流转，你不需要手工搬：

| 层 | 载体 | 说明 |
|----|------|------|
| **热记忆** | `MEMORY.md` 文件 | 当前活跃记忆，按 `##` 分段，AI 实时读写，纯文本可手改 |
| **温记忆** | 记忆表 | 结构化条目，支持全文检索 |
| **冷记忆** | 归档条目 | 超出预算后降级留存，需要时可召回 |

你能用到的功能：

- **自动回忆** —— 每次对话开始前，应用会检索与本次话题相关的记忆注入上下文，AI 会把它当参考资料而不是指令。
- **主动读写** —— AI 可以把「你偏好的写法」「上次踩的坑」写进记忆，也能主动搜索历史记忆。
- **每日自动整理** —— **设置 → 记忆** 可开启定时整理，合并重复、清理过期、把冗长条目压缩成摘要，并设置降级阈值。
- **记忆面板** —— 右侧面板「记忆」可查看三层内容、搜索、手动触发一次整理。
- **作用域** —— 全局记忆（跨项目共享）与项目记忆（只在该项目内生效）分开，落在第 1 节说的两个目录里。全局会话用的就是跨项目那一份，所以全局会话记得住哪个项目干过什么、你偏好什么，派活时才派得准。

> [!TIP]
>
> 记忆是文件 + 数据库，你可以随时手工编辑 `MEMORY.md`，也可以直接删掉不想要的条目。

## 9. 人格系统

人格只影响**输出给你的那段话**——语气、措辞、详略——不参与任务决策，所以换人格不会让事情跑偏。

- **人格管理**（设置 → 人格管理）：新建、编辑、复制人格，每份人格由身份（我是谁）与灵魂（我怎么说话）两部分组成，还可定制认知与行为准则。
- **内置预设**：桃子、老郑、贾维斯、小爪、婷姐、阿明，各有风格。
- **AI 辅助创建**：描述你想要的人格，自动生成初稿再手工微调。
- **绑定**：可以设全局默认人格，也可以给单个会话或单个项目指定不同人格。
- **作用域**：全局人格库与项目人格库分开管理。

## 10. 它能动手做什么

AI 具体能使什么，取决于当前会话类型与权限模式，以下是产品已具备的能力面：

| 类别 | 能力 |
|------|------|
| 文件 | 读、写、编辑、列目录、按文件名匹配 |
| 内容检索 | 全文搜索、代码图谱索引与语义检索（大项目找调用链更快） |
| 终端 | 执行 Shell 命令，支持本地与工作目录；长命令有输出限额保护 |
| 浏览器 | 内置浏览器导航、快照、点击、输入，可用于查资料和验证网页效果 |
| 图片 | 文生图（需在插件里指定图像模型）、读取图片内容 |
| 桌面 | 整桌面截图（用于取证或让你看清当前状态） |
| 远程 | SSH 连接管理、远端目录作为项目工作区、远端命令执行 |
| 子任务 | 派发子 Agent 并行处理独立问题，嵌套深度受限，结果汇总回主会话 |
| 任务管理 | 步骤清单的增删改查与状态跟踪 |
| 定时 | 创建 / 管理定时任务，见第 13 节 |
| 渠道 | 收发消息、群与成员查询，见第 12 节 |
| 提问 | 需要你做选择时弹出选项卡（可多选、可补充说明） |
| 扩展 | 调用插件、Skills、MCP 服务器提供的工具 |

工具不会一次性全部塞进上下文：核心工具直接在系统提示词里，其余的 AI 按需查询和调用，因此工具再多也不会拖慢对话。

## 11. 扩展能力：插件 / 扩展 / Skills / MCP

四个入口都在设置页，作用不同：

- **插件**（设置 → 插件）：内置能力开关，含图像（文生图）、浏览器、代码图谱、桌面控制。可启用 / 停用，并为其指定独立模型。
- **自定义扩展**（设置 → 自定义扩展）：安装本地扩展包，扩展可以带来新工具和自定义界面组件。
- **Skills**（设置 → Skills）：给 AI 装配「某类任务的标准做法」。支持查看已安装列表、从在线市场安装、从本地文件夹安装。
- **MCP**（设置 → MCP）：连接外部 MCP 服务器，把它们提供的工具接进 AI。支持手动添加、JSON 配置导入、在线市场。

用不上时停用即可，停用后对应工具不会出现在 AI 的可用面里。

## 12. 渠道集成（微信 / 飞书 / QQ 等）

把 AI 接到你日常用的聊天软件，在外面也能派活、收结果。**渠道会话是一种特殊的全局会话入口**，不是另一套助手：你在微信里说的那句话，落的还是同一个会派活、会记账的全局会话。

**支持的平台**：微信、飞书、QQ 机器人、钉钉、企业微信、Telegram、Discord、WhatsApp。

**入口**：设置 → 渠道配置。左侧是渠道列表，右侧是选中渠道的配置，底部是**全局渠道设置**——对全部渠道生效，不再逐个渠道重复配。

**接入一个渠道**：

1. 左侧选中一个平台，列表里没有就先添加一个渠道实例。
2. 右侧填凭据：多数平台需要你在平台侧创建机器人 / 应用，把 App ID、Secret、Token 粘进「API 凭据」；微信、飞书还可以走「扫码绑定」，扫一次自动写回凭据。
3. 点「启动」，状态徽章显示「运行中」就算接通了，随时可以「停止」。
4. 在聊天软件里给机器人发消息即可对话（部分平台要求 @ 机器人，取决于平台侧的推送规则）。

**消息由谁处理**：不需要事先绑定项目或会话。每个「渠道 × 聊天 / 群」在第一次来信时会自动开一个专属会话，同一个聊天或群后续的消息都落回那个会话，所以可以连续追问。应用在后台运行即可，不要求界面停在哪个会话上。

**结果怎么回到你手上**：全局会话把派下去的活整理成一段话之后，这条输出会**直接发回渠道**——你在微信、飞书里就能收到，不需要回到电脑前翻会话。任务什么时候回来它什么时候推，不用你守着。

**全局渠道设置**：

- **回复设置** —— 所有渠道的自动回复用哪个**人格**、哪个**模型**。
- **功能开关** —— **自动回复**（关掉后收到消息不再自动回复）、**自动启动**（应用启动时自动连接已启用的渠道）。
- **安全权限** —— **命令需授权**：开启时渠道会话每次执行命令前都会请你确认。

## 13. 定时任务与任务看板

### 定时任务（左侧栏 → 扩展 → 自动化）

到点自动跑一件事，适合日报、定期巡检、批量整理。

除了跑一件具体的事，定时任务还有一个用法：**给全局会话安排触发点**。安排之后它会定期自己醒来，翻一遍任务账本、催办还没交出去的活、把这段时间的成果汇总给你——不用你先去问"那件事怎么样了"。这是它主动性的第二个来源（第一个是项目会话干完活回来触动它）。

- 列表视图与日历视图两种看法。
- 新建时可设定周期或单次时间、提示词、执行模型。
- 两种执行方式：**随指定会话执行**（结果出现在那个会话里，能延续上下文）与**后台执行**（不占用会话，工具面更收敛，适合纯自动作业）。
- 支持启用 / 停用 / 立即运行一次 / 归档。

### 任务看板（左侧栏 → 扩展 → 任务看板）

把待办做成卡片：建卡、设状态与优先级、直接派发给 AI 执行，适合管理一批并行任务。

## 14. 外观、语言与快捷键

- **主题**：浅色 / 深色 / 跟随系统。
- **配色方案**：黑曜灰、远航蓝、石墨工具、深海青、松林绿、暖曦橙。
- **界面语言**：中文、English，切换后立即生效。
- 其余外观偏好（字号、消息密度、编辑器行为等）在 **设置 → 主题外观**。

## 15. 用量统计与成本

**设置 → 用量统计** 看模型请求的真实开销：

- 时间窗：24 小时（按小时分桶）/ 7 天 / 30 天（按天分桶）。
- 汇总卡：请求数、计费输入 token、输出 token、缓存读取 token、成本、平均耗时。
- 分桶柱状图中失败请求以红色叠加显示，一眼看出哪个时间段在报错。
- 两张汇总表：**按模型**（哪个模型花得多）、**按来源**（会话、子 Agent、后台自动化、辅助请求各自占比）。
- 明细表列出最近 50 次请求，含重试次数与失败原因。

> [!WARNING]
>
> 成本按你在服务商里配置的价格结算；没配价格的模型显示为 `—` 而不是 `$0.00`，避免误读成免费。

## 16. 更新、日志与常见问题

- **检查更新**：设置 → 关于 → 检查更新。可以打开「启动时自动检查」——启动时查一次，之后每 6 小时在后台巡检；**下载与安装始终需要你确认**，不会静默更新。
- **顶栏更新图标**：发现新版本后，顶栏出现一个**琥珀色下载图标**并一直留着（悬停可看状态，下载中显示百分比）。点它打开更新弹窗，并顺带重查一次最新版本；下载完成会自动弹开弹窗提示，在弹窗里重启安装即可。
- **日志**：设置 → 日志 可在线查看与导出；磁盘位置为 `~/.wishful-claw/logs/YYYY-MM-DD.log`。反馈问题带上当天日志能显著加快速度。

| 现象 | 先查这里 |
|------|---------|
| 对话没有任何回复 | 设置 → AI 服务商 → 检查连接；确认 API Key 余额与模型名可用 |
| 提示模型不存在 / 服务商已删 | 重新选定全局激活模型；辅助请求会走补位模型兜底 |
| 后台请求走的模型不对 | 设置 → 运行与性能 → 辅助模型，检查该请求的显式配置与补位模型 |
| 说找不到某个工具 | 该工具所属插件可能被停用；到设置 → 插件 / MCP / Skills 确认启用状态，或当前会话类型不开放该工具 |
| 命令执行频繁弹确认 | 会话权限模式改法见第 7 节；渠道会话看渠道设置 |
| 记忆没被用到 | 右侧记忆面板确认条目确实写入；检查设置 → 记忆 的主动回忆与整理开关 |
| 启动器 / 剪贴板快捷键没反应 | 与其他软件的全局热键冲突，到设置 → 快捷键换一个组合 |
| 安装后没有联网权限 | 防火墙放行应用；企业网络下确认代理设置 |
| 更新下载失败 | 到 Releases 手动下载安装包覆盖安装，配置与数据不会丢 |

再解决不了，把 `~/.wishful-claw/logs/` 当天日志的错误段落带上提问，[问题反馈](https://github.com/wishful-73/wishful-claw/issues) 就能提。
