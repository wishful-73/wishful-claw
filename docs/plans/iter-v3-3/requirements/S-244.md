## 2. 目标

1. **安装时让用户知道自己在装什么** —— 一行说明 + 勾选确认（不是风险墙，不是拦截）
2. **卸载时不留垃圾** —— 插件目录 / session 分区 / 私有 KV 三处一起清

## 3. 现状（2026-10-27 实读源码）

### 3.1 安装链路已有，确认缺失

`src/main/ipc/extension-handlers.ts`：

- `extension:install-from-folder`（`:71-72`）
- `extension:update`（`:83-84`）
- `extension:remove`（`:105-106`）
- `extension:open-folder`（`:114-115`）
- `extension:storage-get` / `set` / `delete`（`:139-155`）

⇒ **安装动作本身通了，但没有任何确认步骤** —— 选中文件夹即装。

### 3.2 卸载只删目录，另两处不清

`extension:remove` 只管插件目录。**不清理**：

- `partition: persist:plugin-<id>` 的 session 数据（S-241 新增，现在还不存在）
- `extension:storage-*` 私有 KV（若存在主程序侧存储）

⇒ 依赖 S-241 落地后才能验证「分区清了没有」。

## 4. 落点

### 4.1 安装确认（一次性、不重复骚扰）

选中文件夹 → 解析 manifest → 弹确认：

```
即将安装插件「<name>」 v<version>
由 <id> 提供 · 第三方

此插件可访问你的文件、程序与数据，并可在你电脑上运行程序。
需额外下载运行文件约 489 MB（安装后再点下载，不会自动下）。
请确认来源可信。

☐ 我已了解，仍要安装
                         [取消]  [安装]
```

- **不勾不能装**（唯一强制项）
- **勾选状态按插件 id 记住**（同一个插件更新时不再问）—— 记录在安装历史里，不进 manifest
- **「需额外下载约 XX MB」是必须项**（老大 14:17「知道有这个功能」的落点之二）：体积取自主程序内置资产表（[S-242](S-242.md) §4.1），不取插件自报。插件无资产则**整行不显示**，不留空行
- **不同文案按级别分**：只声明 `tools` 的插件说明可简化；声明 `views` 的必须带「运行程序」那句

### 4.2 卸载清理（**改口径**：不碰共享资产）

| 清理目标 | 做法 | 备注 |
|---|---|---|
| 插件目录 | 现有逻辑保留（`extension:remove`） | |
| session 分区 | `session.fromPartition('persist:plugin-<id>')` → `clearStorageData()` 后删目录 | |
| 私有 KV | 删 `extension:storage-*` 对应数据 | |
| **已下载资产** | **不删** | ⚠️ 改口径见下 |
| 运行态 | 先关窗口（S-241）、再按 pid 树收子进程（S-241） | |

**为什么资产不跟着删**：资产落在**主程序共享区** `%APPDATA%/WishfulClaw/plugin-assets/`（[S-242](S-242.md) §4.2），不属插件目录。理由是 ①插件更新不重下 ②多插件可共用同一模型 ③卸载时**无法判断还有没有别的插件在用**。

⇒ **清理改为独立入口**：设置页「存储」内列「已下载的插件资产」+ 每项体积 + 单独删除 + 「全部清理」。谁下的、多大、还占不使用中，一眼看清。

**顺序**：停用 → 关窗口 → 收子进程 → 清分区 → 清 KV → 删插件目录。任一步失败记录但不中断后续（尽量清干净）。

## 5. 验收

1. 选文件夹安装 → 弹出确认 → **不勾「安装」按钮禁用** → 勾上才能装
2. 取消 → 什么都没发生，插件列表无变化
3. 装完 → 卸载 → **目录、session 分区、私有 KV 三处都空**（逐个验证，不是「看起来没了」）
4. 同插件更新（版本号变）→ **不再弹确认**
5. 卸载某个已下载 489 MB 资产的插件 → **资产文件仍在**，设置页「已下载资产」列表里能看到并单独删掉
6. 卸载跑着的插件（窗口开着、子进程在跑）→ 先关窗口收进程，再清文件，**不出现文件占用删不掉**
7. 主程序重启后插件列表与卸载状态一致（不出现「列表还在、文件已删」）
8. 装一个声明了资产的插件 → 确认弹窗里出现「需额外下载约 XX MB」；装一个没资产的 → **该行不出现**

## 6. 风险

| # | 风险 | 处置 |
|---|---|---|
| 1 | 确认弹窗变「每次都烦」 | 按插件 id 记住，只在**首次安装**问 |
| 2 | 卸载时文件被占用删不掉 | 先关窗口收进程（S-241），再删；失败记录日志并提示「需重启后清理」 |
| 3 | `clearStorageData` 异步，删目录抢跑 | 串行 await，不并发 |
| 4 | 误删主程序自己的分区 / KV | 分区名前缀强校验必须为 `persist:plugin-`；KV 必须带插件 id 前缀 |
| 5 | **共享资产无人清理**（卸载不删 ⇒ 可能留 1 GB 垃圾） | 设置页「已下载资产」独立入口 + 每项体积 + 「全部清理」；本号必须一起交付，否则就是新造的垃圾堆 |

## 7. 不做什么

- **不做插件权限审核 / 白名单** —— 老大 14:03 定不设防
- **不做签名校验 / 来源验证** —— 本阶段只提示「请确认来源可信」
- **不做插件市场**
- **不做「已安装插件」的自动更新** —— 只支持手动 `update`
- **卸载不删共享资产** —— 见 §4.2，改由独立清理入口负责
