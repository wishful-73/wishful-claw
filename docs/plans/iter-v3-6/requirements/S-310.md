# S-310 · 子 agent 卡片：详情入口从「整行点击」改成「显式文字」

> 状态：**✅ 已实施，门禁待补（runtime sln 被运行中的 worker 锁定），待真机验收**
> 登记：2026-11-04 14:34
> 实施：2026-11-04（见文末「§实施记录」）
> 来源：老大 2026-11-04 14:34 原话「子agent组件卡片点击以后打开右侧面板的详情 这个需要调整一下，从点击卡片变成卡片中有个显示的查看详情的纯文字 点击以后再打开右侧面板」
> 关联：S-308（同一张卡的 header 结构，停止按钮是同一次改动加的）

## 一、现象

`SubAgentCard` 的 header 整行绑了两个动作：

```tsx
onClick={() => {
  if (hasSteps) setIsExpanded((v) => !v)
  handleOpenPanel()          // ← 顺手打开右侧面板
}}
```

想看「这一步展开了哪些工具调用」，点一下行，展开的同时右侧面板也被顶开。两个动作绑在同一个手势上，用户没法只做其中一个。

S-308 改这张卡时（把 header 从 `<button>` 改成 `role="button"` 的 div，好塞停止按钮）沿用了这个绑定，问题一并留下来了。

## 二、裁定

老大口径：**卡片点击不再打开右侧面板**，改为卡片内一个**纯文字**的「查看详情」入口，点它才开面板。

- 「纯文字」= 不加图标、不做成按钮样式，就一行小字，跟 header 右侧那簇状态信息同高度；
- 展开/收起继续由行点击负责，这是卡片自身的内容；
- 打开面板是**跳出这张卡**的动作，得显式表达。

## 三、实施

### 3.1 `SubAgentCard.tsx`

| 改动 | 内容 |
|---|---|
| header `onClick` / `onKeyDown` | 删掉 `handleOpenPanel()` 调用，只剩 `setIsExpanded` 切换 |
| header 右侧 | 新增纯文字入口，`role="button"` + `tabIndex={0}`，`Enter` / `Space` 可触发 |
| 事件隔离 | 新入口 `e.stopPropagation()` —— 否则点「查看详情」会连带切展开 |

放在停止按钮之后、状态簇之前：停止是「中断它」，详情是「看它」，两个动作挨着，视觉上和右侧只读的状态指示分开。

### 3.2 语言包

`chat.subAgent.viewDetail`：zh「查看详情」/ en「View details」。两处都插在 `subAgent.queued` 之后。

### 3.3 没动的地方

- `HoverCard`（悬停看 description / prompt）保留 —— 它和「查看详情」是不同层级的信息，老大没提；
- `SubAgentsPanel`（右侧面板里的子 agent 列表）不动：它本身就在面板里，点条目开详情是对的语义；
- `SubAgentExecutionDetail` 的停止后残留 `running` 降级（同批次改动）属于 S-309 的验收修正，不在本需求内。

## 四、验收点

1. 点子 agent 卡片的行 → 只展开/收起工具列表，**右侧面板不动**；
2. 点行尾「查看详情」→ 右侧面板打开该子 agent 详情，**卡片展开状态不变**；
3. 子 agent 运行中，点「停止执行」不会连带触发展开或打开面板；
4. 纯文本档（S-225 极简）下卡片形态不变，入口仍在；
5. 英文语言包显示 "View details"。
