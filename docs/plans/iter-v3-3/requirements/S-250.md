## 3. 硬约束

1. **渲染零变化**：拆完逐组件真机对比 —— 类名、间距、文案、交互全部一致。拆分不是重构，**不许顺手改样式或补功能**。
2. **对外导出零变化**：`AppPluginPanel` / `UsageLineChart` / `UsageBarChart` / `StatCard` / `RollupTable` / `StructuredInput` / `BrowserToolCard` / `SkillsMenu` / `SearchDialog` / `PreviewPanel` / `SessionSummaryPanel` / `GoalHistoryPanel` / `WorkingFolderSelectorDialog` 的原 import 路径必须仍然可用；被拆走的具名导出（如 `formatCost`、`UsageModelSeries`）从主文件 re-export 兜住。
3. **state 不上提**：拆出的子组件走 props；**不许**为了少传 props 而新建 context 或全局 state（那等于把第 3 类豁免的代价反向制造出来）。
4. **hook 搬家保持依赖数组原样**：`useGitSummary` / `use-message-search` / `useMeasuredSize` 整体搬迁，`useEffect` 依赖数组一字不改。
5. **拆完头部标注清理**：降到 500 行以下后删掉「超标待拆分」三行注释。
