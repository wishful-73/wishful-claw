# S-348 `BrowserSetDevice` 卡片主行显示裸英文 —— `buildSummary` 末行 `return name`

> 状态：✅ **已修复**（2026-11-06 21:2x，刀 39 = `095352ce`）—— `buildSummary` 末行改空串 + 补 SET_DEVICE 摘要/字段分支 + i18n 中英各 4 键 + 新增 `tests/browser-summary-fallback` 8 条；`npm run typecheck` 三配置 0 错、`npm test` **128/128**
> 性质：缺陷（用户可见）。**中危**。
> 归属：本迭代。与 S-270 同一类病、同一处病根的第二个出口。

---

## 一、现象

`BrowserSetDevice` 工具卡的**主行**显示裸 camelCase `BrowserSetDevice`，而中文标题
「浏览器设备模拟」被挤到副行（`browser.BrowserSetDevice.title`，zh `chat.json:949`）。

## 二、根因

`src/renderer/src/components/chat/BrowserToolCard/summary.ts` 的 `buildSummary`
（:77~152）有 7 个分支，**唯独没有 `BROWSER_SET_DEVICE_TOOL_NAME`**，落到末行：

```ts
151|   return name
```

`BrowserToolCard.tsx:105` 是：

```tsx
primary: summary || title,
secondary: summary ? title : undefined,
```

`summary` 拿到非空字符串 `"BrowserSetDevice"` ⇒ `||` 短路，`title` 永远用不上。

**这正是 S-270 修过一次的同类问题**：当时修了 `title` 的兜底（`fallbackTitle` 末行
`return name` → `resolveToolDisplayName`，注释还留在 `BrowserToolCard.tsx:86`），
**但 `buildSummary` 的同一个末行漏了**。8 个工具缺 1 个分支，就漏出来了。

## 三、修法（治本，不是只补一个分支）

只补 SET_DEVICE 分支只能挡住这一个工具，下次加第 9 个浏览器工具照样裸英文。
两步都做：

### 3.1 末行兜底改成空串

```ts
-  return name
+  // 兜底不许回显工具名：`primary: summary || title` 靠空串回落到 title。
+  // 与 S-270 修 `fallbackTitle` 同理（`BrowserToolCard.tsx:86`）。
+  return ''
```

调用点只有 `BrowserToolCard.tsx:82` 一处，`title` 已经是
`t('toolCall.browser.${name}.title', { defaultValue: resolveToolDisplayName(name, t) })`
—— 自带「工具 · 原名」兜底，所以空串回落**永远不会露出裸英文**。

### 3.2 补 SET_DEVICE 分支（有意义的摘要）

工具 input 是 `{ device, width, height }`、output 是
`{ success, device, viewport }`（`lib/tools/browser-device-native.ts:23/45/61`）。
`device` 取自 `BROWSER_DEVICE_MODES = ['pc','iphone','pixel','ipad','custom']`
（`src/shared/browser-device-presets.ts:8`）。

摘要按模式分化，`pc` 是「取消仿真回桌面」不是缺省值（同文件 `:54` 注释）：

| device | 摘要 | i18n 新键（zh / en） |
|---|---|---|
| `pc` | 桌面形态 | `summary.devicePc` — 桌面形态 / Desktop |
| `iphone` | iPhone | 直接用常量字面量 |
| `pixel` | Pixel | 同上 |
| `ipad` | iPad | 同上 |
| `custom` | 自定义 390 × 844 | `summary.deviceCustom` — 自定义 {{width}} × {{height}} / Custom {{width}} × {{height}} |

`device` 非法（工具已经返回 `{success:false, error}`）⇒ 落空串，主行回落到中文标题。

### 3.3 顺手补 `getResultRows`（:187）

`BROWSER_SET_DEVICE_TOOL_NAME` 也没分支 ⇒ 卡片展开后**一行字段都没有**。补
`fields.device` / `fields.viewport` 两行（复用已有的 `fields` 段，新增
`device` = 设备 / Device、`viewport` 已有 = 视口 / Viewport）。

## 四、为什么不是「加个 if 就完」

判断依据：**这是一个兜底位置，不是一处业务分支**。S-270 的教训写在同一文件
注释里 —— 兜底写成 `return name`，等于把「开发者视角的标识符」当成
「用户视角的文案」直接上屏。所有末行 `return name` 都要清掉。

顺带复查：`summary.ts` 其余分支的兜底值（`|| name` 形式）只有 `:124`
`compactText(stringValue(jsonOutput?.clicked) || stringValue(input.selector) || name)`
—— 那一处也在末位，同样改成末位落 `''`。
