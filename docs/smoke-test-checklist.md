## 优化建议

> 不是 bug，但体验上可以更好的点。

| # | 建议 | 说明 | 状态 |
|---|------|------|------|
| 1 | 左侧项目会话列表时间常驻 | 目前 hover 才显示时间，建议一直显示 | 🔧 已实现 |
| 2 | 执行中的会话显示转圈状态 | 会话正在执行时，时间位置改为转圈 loading 图标 | 📌 待办 |
| 3 | 历史消息跨天显示日期 | 消息时间戳如果是跨天的，应显示日期而不仅仅是时间 | 🔧 已实现：1-2 天显示"昨天 HH:MM" |
| 4 | 系统提示注入当前时间戳 | 每次用户发消息时，在系统提示中注入当前时间（如 `当前时间：2025-01-20 14:30`），否则 Agent 无法感知"现在"是什么时候，时间相关表述会随机出错（如把"20分钟前"说成"前天"） | 📌 待办 |
| 5 | 人格混血功能 | 用户可以选择两个现有的人格进行融合，自动生成一份组合后的 Identity + Soul 文件。比如"毒舌+初恋"生成傲娇人格，"苏妲己+极简执行者"生成霸道总裁人格。未来可扩展为拖拽滑块调整混血比例的 UI（如毒舌60%/温柔40%），让用户像调音台一样调配人格风格。基于已有的 PersonaGenerator 实现，本质是两份人格文件的加权融合 prompt。 | 📌 待办 |
| 6 | Agent 写日记功能 | 每次对话结束后，Agent 后台自动写一篇日记（不占用用户时间），记录当天做了什么、遇到了什么问题、学到了什么、甚至对用户状态的观察。输出到 `~/.wishful-claw/diary/YYYY-MM-DD.md`。第二天启动时在系统提示中注入昨日日记摘要，让 Agent 有"连续记忆"的感知。结合人格系统效果更佳——毒舌人格的日记是吐槽风，初恋人格的日记是甜腻风，苏妲己人格的日记是撩人风。本质是给 Agent 一个"自我反思"的出口，让用户感觉 Agent 有灵魂、有成长，而不是每次对话都从零开始。 | 📌 待办 |
