## 2. 现象

官网首屏现在是「把话讲透」的做法，与参考站的「留白 + 一句话」是两个方向。

实读 `site/website/src/sections/hero.tsx:41-82` 与 `content/site.ts:45-74`（2026-11-13）：

| 元素 | 现状 | 问题 |
|---|---|---|
| 眉标 | `心之所向，心想事成`（`BRAND.vision`，`hero.tsx:46`，字距 `0.24em`） | 是品牌愿景，**不是「这是什么」** —— 第一次来的访客看完仍不知道这是什么东西 |
| H1 | `你提需求，` + `它跑全程`（`hero.tsx:47-50`，52px / `sm:leading-[1.15]`） | 文案本身没问题（2026-10-19 老大亲自给的稿），问题在**字号**：1440 宽下只占一行的一半，缺反差 |
| 副标题 | **130 字**一段（`site.ts:61`）：装完就能用 / 四件小事 / 真动手四件事 / 接服务商 / 跑全程 | 把后面 4 个区块的内容全塞进首屏，**后面又各讲一遍**；18px 下折 4~5 行，读不完就滚走了 |
| CTA | 单枚「立即下载」（`hero.tsx:52-60`） | 好，不用动 |
| 大图 | `assetNo 14`，`h-auto w-full` 完整显示（`hero.tsx:68-79`） | 好，2026-11-12 已按参考站对齐（圆角 16px + `ring-1` + 大投影） |

**全站还有 7 个区块**（`App.tsx:35-43`：价值阶梯 / 能干什么 / 为什么是它 / 下载 / 四步开始 / FAQ / 反馈），`advantages` 五张卡每张都是 `quote` + 一大段 `body`（`site.ts:106-164`）。整体是**说服型**页面，不是**展示型**。

## 4. 根因

**不是缺一个好看的标题，是信息密度与视觉层级都平。**

三条，按影响排序：

1. **副标 130 字 vs 标题 52px** —— 副标的信息量和标题倒挂。参考站是「大标题占绝对主导，副标只补一句」，现在是「标题一句话，副标五句话」。
2. **眉标占着最贵的位置却没有信息** —— 首屏第一行是访客目光落点，「心之所向，心想事成」诗意但不回答「这是什么东西」。
3. **区块之间在重复自己** —— 首屏说完「不花钱 + 四件小事 + 真动手 + 接服务商」，`valueLadder` 又说一遍「不花钱」，`quickStart` 又说一遍「接服务商」。删首屏那些，信息不会丢。

## 6. 代价与取舍

（**实施后回填**，2026-11-13 11:29 确认）

- 首屏信息量降约 3/4「不花钱」从首屏主位退到紧随其后的 `valueLadder` 整块 —— `valueLadder` 就在首屏正下方，滚动一屏即可见，**不算藏起来**。这是可以接受的，也是 11-29 砍三短句之后首屏仍站得住的前提。
- 方案 A 推翻 2026-10-19 的 H1 裁定（已获老大 11:26 明示）。h1 与 `valueLadder.note`「先白嫖用起来，要它干重活时再接一家服务商」的呼应关系变弱 —— 由副标末句「活是真干完的，不只是聊给你听」接手。
- **三短句砍掉后首屏反而更干净**：CTA 与大图之间只剩 `mt-12 sm:mt-16` 的呼吸位，回到 2026-11-12 的节奏。信息由副标一句承担，**不靠堆点**。
- 副标加了 `text-balance`：33 字在 `max-w-2xl` 下原本断成「…不只是 / 聊给你听。」（末行只剩 5 字），交给浏览器均衡断行后两行长度接近。这是排版刚需，不是装饰。

## 7. 刻意不做

- **不做三短句**（真干活 / 真本地 / 真透明）—— 老大 11:29 砍掉，与下方 `valueLadder` / `features` / `advantages` 重复。**别再当「方案 A 的一部分」加回来。**
- **不改信息架构**：7 个区块一个不删。`advantages` 五张卡的长 `body` 要不要瘦身，属另一个需求，不在本条。
- **不改居中对齐**：左对齐是分水岭级的重排，单独谈。
- **不碰 `BRAND`**：`site.ts:3-5` 记着 `BRAND` 连带 4 行静态投影面（`index.html` / `download.html` 的 title + description）。本轮只动 `hero`，该约束不触发。
- **不删 `BRAND.vision`**：只把眉标位置让给「心相 WishfulClaw」，字段本身保留（页脚 `site-footer.tsx:14` 还在用）。
- **不引入 Web 字体**：`index.css:104` 是系统字体栈，换字体会拖慢首屏，与「B 格」无关。
- **不动背景动画层**：`ConvergeStreams` + `SiteMist`（S-206）是本站在观感上的既有资产，保留。
