# 内置人格文件精简记录

> 日期：2026-08-30 ｜ 提交：48bf595 ｜ 分支：dev/v2-iter-24
> 目标：在保持语义一致的前提下精简内置人格 .md 文件，降低每次请求的 token 占用。

## 背景

人格四件套（IDENTITY / SOUL / ONTOLOGY / AGENTS）由 `PromptBuilder.LoadPersonaDocuments` 按原文注入 System Prompt 的 `<persona>` 段（预算 20,000 字符），每次请求都会携带。精简叙述性文字可直接、等量地减少 token 消耗。

## 精简原则

1. **语义零损失**：所有行为规则、底线、原则、标志性语句（口头禅、示例对话）全部保留
2. **结构归并**：SOUL/ONTOLOGY 中「小节标题 + 叙述段落」压缩为「加粗要点 + 冒号展开」，去除标题与正文间的重复表述
3. **元数据结构不动**：IDENTITY.md 必须保持 `# 名称` / `> 标语` / 紧跟普通描述段的结构（`PersonaMetadata.Parse` 依赖此格式解析名称、标语、描述）
4. **default 不动**：内置 `default` 人格本身已足够精简
