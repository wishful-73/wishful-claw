## 范围与功能单元

### S-72 运行中有内容时按钮变「发送（排队）」

agent 执行中，输入框有内容时按钮仍是「终止」，用户只能回车发消息。改为复用非流式那套判据：有内容走 `onSend`（上游 `chat-store.sendMessage` 已判忙入队），无内容才走 `onStop`。

### S-73 会话级「请求上下文上限」开关

开一个会话级开关，把模型请求的**有效窗口**夹到 256K —— 上下文越大越贵，给上限后到阈值就压缩，整体更省。

实现落在「provider 定稿后克隆一份、把 `contextLength` 夹到上限」，四条读取点（`ShouldCompress`、尾部预算、钉住预算等）零改动即全部生效。只对真实窗口 > 256K 的模型生效；模型档案里的 `contextLength` 保持真值，只有运行时有效窗口变。

### S-74 输入框底部工具栏控件间距收窄

各控件自带 `px-2`，再叠 gap 显得疏远。gap 收到 0.5（左组）/ 1（右组），分隔交给控件自己的内边距。

### S-75 聊天窗最低宽度保护

展开 / 拖宽任一侧面板挤到聊天窗下限时，自动收起**另一侧**面板；拖拽路径与展开路径走同一套判定。右侧上限算法改为 `视口 − 聊天窗最低宽度`。

### S-76 压缩片段各自显示那一刀的时间

长任务被压缩切分后，每个片段下方原本显示**同一个**耗时与更新时间。改为**首尾相接**：每段 `createdAt` = 上一刀时间、`updatedAt` = 这一刀时间；末段另加整轮总耗时（`09:20 · 1m30s · 共 8m34s`）。只影响被压缩切分过的消息，无压缩的消息行为不变。

### S-77 会话 todo 单行显示 + 只显示当前批次

两个问题：任务显示占多行；上一批做完了不清理、还在累加条数。

- 每条任务**单行截断**，hover 出全文
- 只显示**当前批次**（判据：前一批全部 completed ∧ 新任务创建时间 ≥ 前一批最后更新时间），**数据一字不动**

### S-78 审批弹窗正文过长撑出视口

未开 YOLO 时审批弹窗正文是 shell 命令全文、不截断，撑出弹窗边界。加了高度上限 + 正文区自滚 + `whitespace-pre-wrap` + `break-words`；等宽字体只给审批弹窗（`descriptionVariant: 'code'`），其余 `confirm()` 调用点零改动。

### S-79 沙箱模式：工具参数的工作目录边界校验

目标是不让 agent 跳出工作目录做别的事。开关**全局、默认开**：

- 项目会话 = 该项目 `workingFolder` 单根
- 全局会话与渠道会话 = 所有已注册**非 SSH** 项目 `workingFolder` 的并集
- 越界**直接拒绝**，不转审批、不静默回退

落点在**路径解析层**（`ToolHelpers` 的三个 helper + `ShellExecuteTool` 的 `ResolveCwd`），新工具自动受益，不需要维护「哪个工具的哪个参数是路径」的映射表。

系统提示词同时加了一段 `## Sandbox mode` 把边界告诉模型。**该段必须同步进 `SystemPromptCache` 的 cacheKey**，否则切换开关会静默命中旧提示词。

⚠️ **机制边界**：只校验**工具参数里的路径**，命令行内部不受约束 —— cwd 一旦合法，命令字符串里想碰哪里碰哪里。要真隔离只能靠 OS 级手段，不在本轮范围。文档与设置项文案都已按此写准。

### S-80 文件写入的 BOM 处理不一致

契约：写入**默认一律不写 BOM**；只有 `.ps1` / `.bat` / `.cmd` 例外，且只**保留目标文件原状**（原本没有也不补）。`.sh` 故意不入白名单（BOM 会让 Linux 报 `bad interpreter`）。

产品里唯一制造 BOM 的两处是 memory 初始化，已去掉 `Encoding.UTF8` 参数。存量带 BOM 的文件不主动清洗（那是改用户数据）。

### S-81 输入框上方多条提示互相遮挡

会话 todo 摘要条是**悬浮**的（绝对定位向上展开），正好压住常驻的 API Key 提醒 / 排队面板 / Goal 条。改回**流式占位**。

### S-82 人格选择器 trigger 与同排控件样式不一致

补齐 `h-8` / `rounded-lg` / `gap-1.5`，并补上原来缺的 `outline-none` 与 focus ring。

### S-83 工具栏「提示词优化」入口换成上下文上限开关

优化入口换成一个 `Gauge` 图标的上限开关。

### S-84 会话级「请求上下文上限」并入上下文环面板

把上限收进上下文环（点环弹面板）：面板可 hover / 单击常驻展开，含用量、上限**滑条**（200K ~ 当前模型窗口、步长 4K）、立即压缩。上限与**模型 id 绑定**，换模型即作废。删掉了独立的 Gauge 图标控件与双击压缩入口。

### S-85 会话级「压缩阈值」滑条

压缩阈值此前只有全局设置，会话级无从覆盖。面板里加滑条（30%~90%、步长 5%），哨兵值 `0` = 跟随全局，配还原按钮。DB 新增 `sessions.compression_threshold`（REAL）。

### S-86 memory_hot_write 三处缺陷

节标题匹配用的是裸子串，出三个问题：

1. **无行首校验** —— `### 协作纪律` 含子串 `## 协作纪律`，会命中三级标题、静默写错位置
2. **重复标题只改第一处** —— 第二份整块原样留着，不报错
3. **删节向前无下限吃换行** —— 文件头变成 `# Long-Term Memory## xxx`

改法：抽共用 `FindSectionHeadings` 带行首校验；重复标题全量归一到第一处；`RemoveSectionAt` 不再向前吃换行；`NormalizeGluedHeadings` 兜底。这块此前**零测试覆盖**，补了 31 条断言。

## 已知限制

- **沙箱只覆盖工具参数里的路径**，命令行内部不受约束（详见 S-79 节的机制边界）。真隔离需要 OS 级手段，本轮未做。
- **沙箱对 SSH 项目不生效**：远程工作目录不参与本地边界集合。
- `Monitor` 工具与 MCP 工具自身的路径参数不在覆盖范围（前者 schema 无路径参数，后者参数结构由各 server 自定义）。
