## 一、证据

`src/main/lib/logger.ts` 已经是一套完整的文件日志设施：

```ts
export function logError(source, message, options?: { stack?; extra? })
export function logWarn (source, message, options?: { stack?; extra? })
export function logInfo (source, message, options?: { extra? })
export function logDebug(source, message, options?: { extra? })
export function getLogDirectory(): string
export function listLogFiles(): LogFileInfo[]
export function readLogFile(name): LogFileContent | null
export function cleanupOldLogFiles(days): LogCleanupResult
```

**15 个文件已经在用**（`index.ts` / `updater.ts` / `ssh-test.ts` / `plugin-lifecycle.ts` / 多个 `ipc/*` …）。

但主进程仍有 **59 处裸 `console.log`**：

| 目录 | 处数 |
|---|---|
| `channels/`（钉钉 / 飞书 / QQ / 微信 / WorkBuddy） | **42** |
| `mcp/` | 6 |

## 二、影响

打包版 Electron 主进程没有控制台窗口，`console.log` 的输出**直接丢弃**。结果是：

- 用户在设置页「查看日志」里翻文件，**渠道相关的一切都看不到**
- 老大排查「钉钉消息没回」「飞书重复消息」时（`feishu-service.ts` 里就有 `Skipping duplicate message` 这种关键信息），只能靠 `dev` 实例挂在终端上看
- 而 `channels/` 恰好是**最需要事后看日志**的模块（异步回调、长连接、第三方 webhook）

对照：`ssh-test.ts` 只有 1 处 `console.log` 的地方反而是走 logger 的 —— 说明不是「有意不用」，是**没人回头统一**。

## 三、修法：按目录分批，`channels/` 先做

1. **`channels/` 42 处**（第一批，单独 commit）—— 收益最大
2. `mcp/` 6 + `lib/` 5 + `ipc/` 4 + `index.ts` 1 + `ssh/` 1（第二批）

替换规则：

| 原 | 换成 |
|---|---|
| `console.log(...)` 普通过程信息 | `logInfo('<module>', message)` |
| `console.log(...)` 详细报文 / 调试 | `logDebug('<module>', message)` |
| 想带结构化数据 | `logInfo('<module>', msg, { extra: { … } })` |

`source` 用现成的模块名（日志里已经在用 `'provider'` / `'ssh'` 一类）。

## 四、本单明确不做

- **不动 `console.error` / `console.warn`**。普查只统计了 `.log`；`.error` / `.warn` 在 main 侧另有量，且可能在 `installGlobalExceptionHandlers` 里有兜底，一次改两个面风险翻倍。要动另立单据
- **不改 `logger.ts` 的签名或分级策略**
- **不给 `logger.ts` 加「自动把 console.log 转进文件」的 monkey-patch**。那会让调用点继续散着写、还看不出谁在写日志；老大 11-05 明确过「不加弯弯绕绕的东西」

### 6.1 有意保留的那一处

`src/main/index.ts:172` 的 `console.log` **没改**。那是 renderer `console-message` 事件的透传桥 —— 它要保留渲染层的原始来源标签，落盘由紧邻的下一行 `logWarn` 负责。改成 `logInfo` 反而会丢来源信息。

### 6.2 顺手清掉的重复写入

`native-worker` 的 `exited` 事件原来是 `console.log` + `logInfo` **双写**，同一件事落两遍。去掉重复那半，只留 `logInfo`。
