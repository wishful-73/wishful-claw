## 二、参考项目怎么做的（ZCode `DESIGN.md`）

实读它的标题结构：

配色（核心语义色 / 文字色 / 边框色 / 语义反馈色 / 阻塞交互色 / 工作流时间线色 / 遮罩与工具色）→ 配色使用规则 → 字体（字族 / UI 字体 token / 字号角色 / Markdown 字阶 / 排版规则）→ 间距 → 圆角（容器层级 / 已批准的例外 / 基础控件 / 对话框 / 菜单与选中遮罩 / 形状例外与一致性）→ 尺寸（基线 / 规则）→ 组件（按钮 / 输入 / 卡片与面板 / 菜单·弹层·对话框 / 选项卡与选中态 / 聊天·工具·开发者 UI）→ 层次与景深 → 动效 → 工作区布局 → 响应式 → 无障碍与国际化 → 实施指引 → **`## Do`** / **`## Don't`**

两个特征值得抄：

1. **每条规则都写「为什么」+「例外在哪」** —— 不是「圆角一律 8px」，而是「容器层级 → 各级圆角 → 已批准的例外」。
2. **末尾 `Do` / `Don't` 两节** —— 可以直接当 review checklist 用。
