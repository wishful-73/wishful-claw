## 一、它是什么

「新会话默认用哪个模型」的绑定 —— `{ providerId: string; modelId: string }`（类型 `ModelBinding`）。

**设置面板里没有它。** 「运行与性能 → 会话默认值」区块（`RuntimePanel.tsx:126-179`）装的只有两项：**项目会话默认协作模式**（`projectSessionDefaultCollaborationMode`）与**默认权限模式**（`coworkDefaultPermissionMode`），i18n 自述原话「设置新建会话的协作模式与默认权限模式」（`zh/settings.json:1510`）。模型不在其中。
