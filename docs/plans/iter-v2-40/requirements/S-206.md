## 一、动机

官网首屏**目前是纯文案 + 一层扫光，没有任何背景层**。参考站 `https://astra-gate.si/` 的首屏有持续运行的背景动画，观感明显更「活」。老大指定参考它，给我们的首屏加同性质的东西。

**官网现状（只读勘察坐实）**：

| 项 | 现状 |
|---|---|
| Hero 结构 | `website/src/sections/hero.tsx` —— `<section className="pt-28 pb-16 sm:pt-36">`，内层标题 + 两入口（快速开始 / 下载桌面版） |
| 首屏大图 | **2026-09-23 已撤掉**（`hero.tsx` 注释留有记录），回归纯文案 |
| 现有动效 | **仅首屏文字扫光** —— `shine shine-muted` 挂内层 `span`（注释写明：挂内层是为避免与 `reveal` 动画互相覆盖）；整段铺光由 `h1` 的 `::after`（`index.css` 的 `.hero-shine`）+ `data-text` 属性实现 ⇒ **两处需同步改**。**⚠️ 本次可能整个撤掉它 —— 见 §5.1（08:58 定：保动画、扫光让步）** |
| 背景层 | **无**（三页面均 `<SiteHeader/><main/><SiteFooter/>`，`main` 下面就是纸面底色） |
| 视觉语言 | `index.css` 设计 token：**浅色纸面底**（`--color-paper:#ffffff` / `--color-paper-soft:#f7f8fa`）+ 单一**琥珀强调色**（`--color-accent:#ea580c`），大留白、13px 圆角、细边框。**2026-09-21 指定参考 reasonix.io** |

## 二、参考站实测（只读勘察，内置浏览器实测）

> **参考站归属（2026-10-15 11:45 补记）**：`https://astra-gate.si/` **就是这个项目自己的官网** —— 源码 `239573049/Astra-Gate`（**C# / MIT**，本地 AI 网关 / 反代）。它同时是 **post-1.0 路线 `R-3`（反代）的源码级参考源**，已登记在 `docs/roadmap-post-1.0.md` ⇒ **两条需求看的是同一个东西，别当成两个无关的参考站**。本需求只借它**首屏的做法**，与 R-3 不共用代码。

**结构**：Hero 的 `<main class="astra-home relative isolate …">` 下挂**两层 `<canvas aria-hidden="true">`**：

| 层 | class | 尺寸（backing store） | 作用 |
|---|---|---|---|
| 底层 | `pointer-events-none fixed inset-0 -z-20 size-full` | **116 × 120**（CSS 拉满视口 ⇒ 约 8 倍放大） | **全视口固定**的最底层，低分辨率画布放大后成柔和色雾/渐变 |
| 上层 | `pointer-events-none absolute inset-0 -z-10 size-full [mask-image:linear-gradient(to_bottom,black_70%,transparent)]` | 1359 × 945 | **只盖 Hero 区块**，**底部 30% 用 mask 渐隐**，叠在色雾之上 |

**动画确认**：稳定态下 3 秒内该 2D 上下文约 **13005 次绘制调用**（≈ 4300 次/秒）⇒ **确为连续动画**，不是静态画一帧；页面 `visibilityState === 'visible'`，排除「后台节流导致的假静止」。

> **观测备注（留给实施时避坑）**：首轮探针（页面刚导航完、只挂了少数几个方法）读到 **0 次调用**，页面完全激活后复测才读到 13005 次/3 秒 ⇒ **用「拦截绘制调用」判断同类站点是否在动时，必须等页面完全激活再读，否则会得到相反的结论。**

**另有一处 CSS 动画**：唯一自定义关键帧是 `astra-pulse`（`4s` / `infinite`），挂在 `.astra-core absolute -inset-10 -z-10 rounded-full` —— Hero 标志块后面的**脉冲光晕**。

**视觉形态（截图所见）**：柔和 pastel 渐变**铺满首屏**（浅蓝 → 淡紫 / 粉），其上浮着若干**极细的线段与圆弧**（无填充、细、浅色、朝向随机），整体像「星座 / 流线」状的漂浮线稿。

**交互与无障碍**：两层 canvas 均为**负 z 层**（`-z-20` / `-z-10`）+ `pointer-events-none` + `aria-hidden="true"` ⇒ **纯装饰**，不拦交互、不进无障碍树。

## 三、目标

**在不动现有文案、配色 token 与版式的前提下，给官网首屏加一层背景动画**，让它从「静态纸面」变成「有呼吸感的纸面」，且**不牺牲首屏速度与可读性**。

## 五、待裁定（动笔前必须拍板）

| # | 决策点 | 我的建议 | 理由 |
|---|---|---|---|
| 1 | **技术路线**：canvas 常驻 rAF ／ CSS+SVG 动画 ／ 静态贴图 | **CSS + SVG**（不上 canvas、不引依赖） | 参考站是常驻 rAF + 每秒数千次绘制调用，为「纯装饰」付这个代价不值；同样的「浮动线稿」用 `@keyframes` + `transform` 走 GPU 合成，零 JS、观感接近，且与我们现有的 `shine` / `reveal` 同为 CSS 动画，**风格统一** |
| 2 | **配色**：照搬参考站的冷调蓝紫渐变 ／ 用我们自己的纸面 + 琥珀同色系 | **用我们自己的** | 参考站是高饱和冷调英雄区，我们官网是 2026-09-21 老大指定的 **reasonix.io 浅色纸面 + 单一琥珀强调色**。照搬会跟既定视觉语言打架，且违反「单一强调色」这条既有约束 |
| 3 | **强度**：明显的动态背景 ／ 极低对比的「几乎看不见在动」 | **极低对比**（倾向于「能感觉到在动，但读文案时完全不受干扰」） | 首屏是转化面，背景只是氛围；同时能天然规避与 `h1` 扫光叠加显脏的问题 |
| 4 | **范围**：只 Hero ／ 整站 | **只 Hero** | 参考站也是 Hero 局部（第二层 canvas 只盖 Hero）；整站铺动画会跟 `/guide` 长文阅读打架 |
| 5 | **无障碍**：`prefers-reduced-motion: reduce` 时 | **关掉动画（退化为静态）** | 纯装饰动效没有必须保留的理由；系统开了「减少动态效果」就应当听话 |
| 6 | **与 S-205 的顺序**：谁先动 | **S-205 文案先落，S-206 随后** | 两者同面（Hero）、同一个文件族（`hero.tsx` + 文案源），文案先定能少返工一轮 |

## 十、2026-10-19 收尾定案（**改写 §五 定案 1 / 4 与 §4.2-3**）

> 同一会话里老大看过实际效果后重新定案，本节覆盖上述旧定案；裁定流水见 `changelog.md` 2026-10-19 节。提交 `502b1c5f`。

### 10.1 技术路线：**改用 canvas**（逆转 §五 定案 1「CSS + SVG」）

- 老大看过 CSS 版效果后要「更像参考站」的螺旋与尾迹。实现注释记下理由（`sections/converge-streams.tsx:3-14`）：「**纯 CSS/SVG 做不出螺旋与尾迹，所以改用 canvas**」。
- 落地：`sections/converge-streams.tsx`（239 行）—— 单帧 `requestAnimationFrame` 循环，13 档邻近色相 `PALETTE`，束数 `clamp(round(w*h / AREA_PER_STREAK), 36, 220)`。
- **代价（已知、接受）**：从「零 JS」退回「常驻 rAF」。缓解措施：`prefers-reduced-motion` 一帧不画（`:78`）、`visibilitychange` 停/启（`:212`）、`aria-hidden`（`:238`）。**未做**：滚出视口后暂停（见 §10.5 ⚠️）。

### 10.2 范围：**收束层只首屏、雾层整站**（收窄 §五 定案 4「只 Hero」）

- 落地：① 首屏光束收束层 `converge-streams` 只挂 `hero.tsx`；② 整站暖色雾 `sections/site-mist.tsx` 挂三张页面（`App.tsx` / `doc-page.tsx` / `download-page.tsx`）。
- 旧定案「只 Hero」的理由是「整站铺动画会跟 `/guide` 长文阅读打架」—— **雾层是静态 CSS 渐变 + 极慢漂移，不构成干扰**，故放开；真正动的收束层仍只在首屏。

### 10.3 顶栏：**首屏透明、滚动后回玻璃底**（逆转 §4.2-3「不动 `SiteHeader`」）

- 落地：`components/site-header.tsx:22-26` —— `scrolled`（>8px）前 `bg-transparent`，之后 `bg-paper/85 backdrop-blur`。
- 目的：让整站雾层在首屏顶部不被一条实心栏切断。

### 10.4 配色：仍守「纸面 + 琥珀」（§五 定案 2 未被推翻）

- 收束层用的是**13 档邻近暖色相**，不是单一琥珀 —— 属于「一层动画内部的渐变」，不是「引入第二个强调色」。**§六 判据 2 按「强调色仍是琥珀」解释**，不按「画面里只能出现一种颜色」解释。
