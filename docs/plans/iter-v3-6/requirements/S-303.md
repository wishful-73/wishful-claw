## 三、为什么该剥

1. **产品定位**：老大明确「大部分用户不写代码，这东西没用」；
2. **上场率低**：程序员有用，但使用频率不高；
3. **体积**：42.5 MB 占安装后 414.6 MB 的 10.3%，而多数用户一辈子不会触发；
4. **副作用**：不写代码的用户，agent 工具列表里多一堆看不懂的工具；索引还可能扫到不该扫的目录。

## 四、剥离形态（2026-11-02 17:50 实测更正）

**先更正登记时的错误认知**：我原来写「CodeGraph 是进程内库，要拆成 MCP 服务端」。实测不是。

真实调用链（`codegraph-handlers.ts` / `AgentRuntimeCodeGraphExecutor.cs` 逐行核对）：

```
Renderer            codegraph-tool.ts
  → agentBridge.request('codegraph:tool')
Agent 运行时        AgentRuntimeCodeGraphExecutor
  → AgentRuntimeReverseRequests.RequestAsync('codegraph:tool')
Main                ipc/codegraph-handlers.ts  handleCodeGraphTool
  → readCodeGraphEnabled()（查 app-plugin-store 的 codegraph 项）
  → getNativeWorker().request('codegraph/<action>', input, 120s)
原生 worker 进程    WishfulClaw.Worker.exe
  → WorkerModuleCatalog.Default 最后一项 new CodeGraphModule()
```

**跨进程的那层早就有了** —— `WishfulClaw.Worker.exe` 是 native AOT 独立进程，CodeGraph 只是编译期并进去的一个 `IWorkerModule`。用不着 MCP 服务端。

⇒ **真正要剥的只有 42.5 MB 原生语法库**。`WishfulClaw.CodeGraph.dll`（1.8 MB）留主包，不值得为它上 `AssemblyLoadContext`。

| 项 | 体积 | 处置 |
|---|---|---|
| `tree-sitter*.dll` × 18 | **42.5 MB** | 按需下载到 `{dataDir}/plugins/codegraph/grammars/` |
| `WishfulClaw.CodeGraph.dll` | 1.8 MB | 留主包（已 AOT 并进 exe） |

**体积账（别按未压缩算）**：安装后目录 **414.6 → ~372 MB**（-42.5 MB）；`setup.exe` **108.5 → ~88 MB**（原生代码压缩率约 2:1，42.5 MB 落盘只省约 20 MB）。Electron 本体不变。

**顺带发现的现成坑**：`channels.ts:376-378` 定义了 `codegraph:download-assets` / `remove-assets` / `download-progress` 三个频道，**handler 一个都没注册** —— `registerCodeGraphHandlers()` 只 handle 了 `ASSET_STATUS`。`codegraph-assets.ts:9` 注释写着 `bundled only — no online download`。下载链路得从零建。

**明确不做**：tree-sitter 语言裁剪（razor 10.59 / cpp 5.24 / scala 3.92 / haskell 3.74 / julia 2.62 / ruby 2.10 = 28.2 MB）。老大 2026-11-02 14:09「这个不着急砍语言」—— 整体剥离收益更大（42.5 MB），裁语言是白做。

### 10.2 消费方式：不用 submodule

独立仓库 + 版本号引用。理由：

- submodule 把版本锁死在一个 commit 上，升级要同时动 `.gitmodules` 和索引，容易出「本地跟远程不一致」
- 克隆要带 `--recursive`，CI 里 submodule 拉取失败排查起来很烦
- CodeGraph 的改动节奏跟主仓不同步，用版本号才对得上

具体形式**已定案（2026-11-03）**：**不打包引用，走插件资产下载** —— 独立仓产出 `codegraph-win-x64.zip`（9.7 MB，`bin/codegraph.exe` + `e_sqlite3.dll` + 30 个 `grammars/*.dll`），主仓 `plugin-asset-catalog.ts` 登记下载地址，用户点「下载代码图谱」按需装到 `{dataDir}/plugins/codegraph/`。**否掉的两种**：NuGet 私有包（要配源、要认证，用户装不上）、submodule（见上）。
