# S-166 通用图片生成：不要求单独配一个图像模型

- **登记**：2026-09-29 17:51 —— 老大对 S-162 的追加：「162 我们现在还缺图片生成，当前的图片生成是需要去配置专门的模型，我想要一个通用的，当前模型就能调用的图片生成」
- **定位**：与 S-162 是**姊妹需求但彼此独立** —— S-162 管「图出来之后怎么拿走」，本条管「图怎么出来」。**不并入 S-162**（一动渲染端出口与落盘，一动生图链路，合并会变成一需求两刀）
- **分支**：`dev/v2-iter-37`
- **状态**：📝 已登记，待实施（**方向待裁定**）

---

## 一、诉求

现在的生图能力**强依赖一个单独配好的图像模型**；老大要的是「**通用的、当前模型就能调用**」的图片生成。

## 二、现状链路（2026-09-29 实读）

```
ImageGenerate 工具（模型侧）
  → AgentRuntimeImageGenerateExecutor.cs:42   反向请求 "image:generate"
  → src/main/ipc/reverse-handlers/image-reverse-handler.ts
  → POST {baseUrl}/images/generations          ← OpenAI Images API
```

`image-reverse-handler.ts` 的三个关键点：

| 行 | 内容 | 后果 |
|---|---|---|
| `:38` | `const model = (params.model as string) \|\| 'dall-e-3'` | **默认硬编码 DALL-E 3** |
| `:47-49` | 从 provider store 里找**第一个** `type === 'openai'` 且有 apiKey 的 provider | 只有 OpenAI **类型**的 provider 才会被选中 |
| `:51-56` | 找不到就直接失败：`No OpenAI-compatible provider with API key configured` | ⇒ **对话用 DeepSeek / 智谱 / Anthropic 的用户，生图直接不可用** |

⇒ 这就是「需要去配置专门的模型」的确切含义：**不是配一个图像模型，而是必须额外存在一个 OpenAI 类型的 provider**。

## 三、三条可能的路径（**方向待裁定**）

| # | 路径 | 做法 | 代价 / 风险 |
|---|---|---|---|
| A | **走当前对话模型的多模态输出** | 让模型在 chat completion 里直接吐图（Gemini `inlineData` / GPT-4o image output / 豆包·通义等），解析后入库 | **只有部分模型支持**；不支持的模型仍无图可出。需要 provider 侧解析图像输出块（我们目前只解析文本 / 思考 / 工具调用） |
| B | **不限定 OpenAI 类型，改用当前正在用的 provider** | `:47` 的筛选放宽到当前激活 provider（或其图像端点映射） | 现实是**多数 provider 的图像 API 端点与形状各不相同**（智谱 CogView / 豆包即梦 / 通义万相…），要逐个适配，工作量大且会持续漂 |
| C | **保留 images API 通路，但把端点做成「可自由配置」** | 用户可指定任意 OpenAI 兼容的图像端点（baseUrl + key + model） | 仍然是「要单独配」，**不满足老大诉求**，只能算现状改良 |

**A 与 B 不互斥**：A 是「模型自己会画」，B 是「模型让我们去调别人的画笔」。

### 待老大裁定

1. 走 A（当前模型原生出图）／B（放宽 provider 限定）／A+B 都要？
2. 若走 A：**你日常用的模型是什么？** 这决定 A 是否现实 —— 若主流是 DeepSeek，它不支持图像输出，A 就等于没做。
3. 「当前模型就能调用」是否包含**回落**行为：当前模型不会画图时，自动落回已配置的图像端点？

## 四、实施注意

1. **不要动 S-162 的范围** —— 出口（卡片复制 / 下载 + `SaveImage`）与生图链路是两条独立的路，分别成刀。
2. 反向请求 `image:generate` 的入参里已有 `parameters`（`AgentRuntimeImageGenerateExecutor.cs:78`）；若走 A，需确认它是否携带**当前 provider / model 身份**（现在看起来不带，才会去 store 里自己找）。
